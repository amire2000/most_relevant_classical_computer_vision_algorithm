# Classical Computer Vision with Python

Learn the essential algorithms that make images measurable: filtering,
features, geometry, segmentation, and tracking.

## Course map

- Image representation and colour spaces
- Filtering, convolution, and edges
- Feature detection and matching
- Camera geometry and image transforms
- Segmentation and object tracking

Each lesson will pair the core idea with a small Python implementation and a
practical exercise.

See the [course roadmap](roadmap.md) for the planned sequence. The roadmap is
kept separate from future implementations and lab notes.
